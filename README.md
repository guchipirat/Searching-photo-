# Searching-photo-
# Поиск изображений по текстовому описанию

Проект демонстрирует поиск наиболее релевантных изображений по текстовому
запросу.

## Использованные методы

- ResNet50 для получения эмбеддингов изображений;
- TF-IDF и лемматизация для векторизации текстов;
- XGBoost для оценки соответствия изображения и текста;
- GroupShuffleSplit для разделения данных без пересечения изображений.

## Результаты

| Модель | MAE | RMSE |
|---|---:|---:|
| Константная модель | 0.1819 | 0.2443 |
| XGBoost | 0.1418 | 0.1976 |

XGBoost снизил MAE приблизительно на 22%.
